Classflow v9 — Academic Calendar Exceptions + Week/Month Heatmap

NEW: Student calendar date panel can record holidays, term breaks (date ranges), and cancellations of individual lectures. Weekly timetable classes are suppressed on affected dates, while assignment deadlines remain visible, including deadlines not associated with a lecture that day. Calendar dates with exceptions have an amber dot. Exceptions can be removed and are saved in browser localStorage under classflow_calendar_exceptions.

NEW: Student dashboard heatmap has Week / Month selection, previous/next navigation, Today button, labeled dates and counts for pending/completed/overdue tasks. Clicking a heatmap date opens the calendar on that date. Heatmap responds to assignment status and deadline changes.

This is a local frontend prototype. Academic holidays are entered manually; there is no automatic official university holiday feed, remote synchronization, or verified access control. Existing C19 timetable, PDF/OCR import, deadline workflows and professor workspace remain.

To run: npm.cmd install ; npm.cmd run dev
