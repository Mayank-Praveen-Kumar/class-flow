Classflow v7 — MIT Bengaluru, C19 Section, Semester 1 (2026–27)

The student profile and professor demo profile use the C19 subjects. 20 weekly sessions are preloaded in Daily Timetable. The professor demo shares the same class deadlines.

To run: npm.cmd install ; npm.cmd run dev

If an earlier Classflow version is open on localhost:5173, close it first. Existing C19 data is saved in separate localStorage keys.

The timetable includes 20 scheduled sessions, including CAEG Lab and PPS Lab. Breaks and online-only courses are not scheduled. This is a browser-only demo: account verification and professor permissions are not secure without a backend.
