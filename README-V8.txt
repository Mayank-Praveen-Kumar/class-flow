Classflow v8 — Calendar ↔ Timetable Sync

NEW: Selecting a date in the student Calendar shows the recurring weekday timetable for that exact date. Deadlines are attached directly to matching subject lectures ONLY when the deadline's full date matches the selected date. Deadlines without a matching class are listed separately. Status changes update the calendar and heatmap as before. Professor calendar retains a deadline-focused view.

Example: Wednesday 14 October 2026 shows Wednesday C19 classes (EMSB, PPS, FEE, CM, PPS Lab). A CM deadline due 2026-10-14 appears beside CM, not on other Wednesdays.

NOTE: Recurring timetable does not automatically exclude holidays or term breaks. Demo app stores information in browser local storage; no real account synchronization.

Install: npm.cmd install
Run: npm.cmd run dev
